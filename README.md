# 游戏翻译语言包对比工具

## 简介

这是一个用于对比 Excel 文件的工具，专门针对两个不同版本的语言包进行比对。它能够检测同一 Sheet 中相同 ID 在特定语言列下的翻译差异，支持多 Sheet 并行处理，可高效识别数据间的不一致、缺失及其他潜在问题。

## 主要功能

- **多语言包对比**：自动识别两个语言包文件的共同 Sheet，支持批量对比
- **灵活配置**：为每个 Sheet 单独配置文本 ID 列和翻译列，或使用统一配置
- **全面翻译差异分析**：识别翻译不一致、新增文本、删除文本等所有差异类型
- **高性能处理**：多线程并行处理，支持大型语言包和大量 Sheet
- **详细报告**：生成包含统计信息和详细翻译差异列表的 Excel 报告

## 系统要求

- Windows 操作系统
- Python 3.7+
- 依赖库：`wxPython`、`pandas`、`openpyxl`、`xlsxwriter`、`numpy`

## 使用指南

### 1. 启动程序

```bash
python newid.py
```

### 2. 加载语言包文件

1. 点击"选择表A"，选择旧版本语言包 Excel 文件
2. 点击"加载表A Sheet"按钮
3. 点击"选择表B"，选择新版本语言包 Excel 文件  
4. 点击"加载表B Sheet"按钮

程序会自动显示两个语言包文件的共同 Sheet 列表（如 UI、对话、任务等）。

### 3. 选择要对比的 Sheet

- **全选**：点击"全选"按钮，对比所有语言模块
- **全不选**：点击"全不选"按钮
- **手动选择**：在列表中勾选需要对比的语言模块（如只对比 UI 翻译）

### 4. 配置翻译列

#### 方法一：统一配置（推荐）
1. 点击"统一配置所有表格..."按钮
2. 设置：
   - **ID 列名**：文本 ID 列（如 TextID、StringID）
   - **表A 对比列名**：旧版本的翻译列（如 Chinese、English）
   - **表B 对比列名**：新版本的翻译列（通常与表A相同）
3. 点击"保存"

#### 方法二：单独配置
1. 点击"单独配置选中表格..."按钮
2. 为每个 Sheet 分别设置文本 ID 列和翻译列
3. 双击 Sheet 名称也可以打开配置对话框

### 5. 设置对比选项

- **忽略大小写**：对比翻译时忽略字母大小写差异
- **去除前后空格**：自动去除翻译文本前后的空格

### 6. 开始对比

1. 点击"开始比对"按钮
2. 程序会显示处理进度和剩余 Sheet 数量
3. 对比完成后会显示翻译差异统计信息

### 7. 导出翻译差异报告

1. 点击"导出差异报告..."按钮
2. 选择保存位置（默认文件名为 output.xlsx）
3. 点击"保存"
4. 导出完成后会自动打开文件所在文件夹

## 翻译差异报告

导出的 Excel 报告包含以下工作表：

### 1. 对比总览
- 基础统计信息（语言包 Sheet 总数、共有模块数量等）
- 各语言模块详细统计（总文本 ID 数、匹配数、翻译差异数等）

### 2. 翻译不一致详情
- 列出所有翻译内容不一致的记录
- 包含：语言模块、文本ID、旧版本翻译、新版本翻译

### 3. 新增文本详情
- 列出新版本中新增的文本记录
- 包含：语言模块、文本ID、新版本翻译

### 4. 删除文本详情
- 列出旧版本中被删除的文本记录
- 包含：语言模块、文本ID、旧版本翻译

## 性能特点

- **多线程并行**：根据 CPU 核心数自动调整线程数，最多支持 64 个并发线程
- **智能缓存**：文件和列信息缓存，避免重复读取
- **内存优化**：大文件自动分块处理，支持超大 Excel 文件
- **算法优化**：小数据集使用简单算法，大数据集使用向量化算法

## 使用技巧

1. **大型语言包处理**：程序会自动预加载数据，首次可能稍慢，后续处理很快
2. **列名配置**：支持手动输入列名（如 Chinese_CN、English_US），也可以从下拉列表选择
3. **统一配置**：如果所有语言模块的列结构相同，建议使用统一配置功能
4. **内存管理**：处理超大语言包时建议关闭其他占内存的程序
5. **版本管理**：建议将旧版本作为表A，新版本作为表B，便于理解报告内容

## 应用场景

- **版本更新检查**：对比新旧版本语言包，确保翻译更新完整
- **本地化质量控制**：检查翻译一致性，发现遗漏或错误的翻译
- **多语言同步**：确保不同语言版本的文本ID保持同步
- **翻译进度跟踪**：识别新增、删除、修改的文本内容

## 常见问题

**Q: 程序提示"未找到 Sheet 的列信息"？**
A: 请重新加载语言包文件，确保文件路径正确且文件未被其他程序占用。

**Q: 对比速度很慢？**
A: 确保系统有足够内存，关闭不必要的程序。程序会根据语言包大小自动优化算法。

**Q: 导出报告打不开？**
A: 确保安装了 Microsoft Excel 或 WPS Office 等 Excel 兼容软件。

**Q: 支持哪些文件格式？**
A: 支持 .xlsx 和 .xls 格式的 Excel 语言包文件。

**Q: 如何处理多语言列？**
A: 可以分别对比不同语言列，如先对比中文列，再对比英文列。
